# U盘邮 · USB Mail

> 把 U 盘插到任意电脑，双击就能用、**不用注册、不用登录任何网站**的本地邮箱客户端。
> 邮件从你的邮箱服务器直达你的电脑，**不经过任何第三方服务器**。

支持 **QQ邮箱 / 163 / 126 / Gmail / Outlook** 及任意标准 IMAP 服务器。

```
┌─────────────────────────────────────────────────┐
│  插上 U 盘  →  双击启动器  →  浏览器自动打开      │
└─────────────────────────────────────────────────┘
```

---

## 为什么需要它

浏览器里的网页**无法自己接收邮件**（浏览器不允许网页打开 IMAP 这类底层连接）。
所以网上那些「打开网页就能收邮件」的临时邮箱，都是把邮件存在**别人的公网服务器**上——
你的邮件内容会经过他们的机器。

**U盘邮的做法：把那台服务器放进你的 U 盘。**
它只监听 `127.0.0.1`，带三平台绿色运行时，目标电脑**什么都不用装**。

---

## 特性

- **零第三方依赖** —— 没有 `node_modules`，不用 `npm install`。IMAP 协议、MIME 解析、Base64/QP 解码、RFC2047 编码字解码全部自研，只用 Node 内置模块。U 盘方案必须如此，否则联网装依赖就会失败。
- **中文完美支持** —— UTF-8 / GBK / GB18030 / Big5，163 的老邮件也不乱码。
- **邮件 HTML 沙箱渲染** —— 邮件里的脚本碰不到你的界面。
- **附件下载** —— 中文附件名正确解码。
- **授权码加密存储** —— AES-256-GCM，密钥是 U 盘内的随机 `.keyfile`（所以同一个 U 盘插到任何电脑都能免重输）。
- **多账户 / 多文件夹** —— 收件箱、已发送、草稿箱随意切换。
- **深色模式 / 窄屏适配**。

## 快速开始

### 1. 获取授权码（不是登录密码！）

**QQ 邮箱**：[mail.qq.com](https://mail.qq.com) → 设置 → 账户 → 开启 **IMAP/SMTP 服务** → 得到 16 位授权码

**163 邮箱**：[mail.163.com](https://mail.163.com) → 设置 → POP3/SMTP/IMAP → 开启 **IMAP/SMTP服务** → 得到授权码

### 2. 准备运行时

仓库不含 `runtime/`（太大）。二选一：

```bash
# 方式 A：用系统已装的 Node（推荐，只要有 Node 18+ 即可）
cd usbmail && node app/server.js

# 方式 B：下载绿色版放进 runtime/ 实现真正免安装
#   到 https://nodejs.org 下载对应平台，解压后重命名为：
#   runtime/node-mac-arm64/    (Apple 芯片 Mac)
#   runtime/node-win-x64/      (Windows)
#   runtime/node-linux-x64/    (Linux)
```

### 3. 启动

| 系统 | 命令 / 操作 |
|---|---|
| macOS / Linux | 双击 `启动-U盘邮.command`（或 `chmod +x` 后运行） |
| Windows | 双击 `启动-U盘邮.bat` |
| 任意 | `node app/server.js` |

浏览器会自动打开 `http://127.0.0.1:8787/`，点 **＋** 添加邮箱即可。

> 启动器会自动寻找 `runtime/` 里的绿色运行时，找不到才退回系统 Node。

## 目录结构

```
usbmail/
├── app/
│   ├── server.js       # 本地 HTTP 服务器 + JSON API + 账户加密
│   └── imap.js         # 自研 IMAP 客户端 + MIME 解码（核心）
├── public/             # 前端（原生 JS，无框架）
├── runtime/            # 绿色运行时（.gitignore，自行下载）
├── data/               # 你的数据（.gitignore，绝不提交）
├── 启动-U盘邮.command  # macOS / Linux 启动器
├── 启动-U盘邮.bat      # Windows 启动器
├── 清除数据.command    # 一键清除账户与缓存
├── test-mime.js        # MIME 解码测试（22 项）
└── test-e2e.js         # 端到端测试（20 项，含假 IMAP 服务器）
```

## 安全说明（请认真读）

这个项目的安全模型很明确，**它不是保险箱**：

| 项目 | 说明 |
|---|---|
| **授权码加密** | AES-256-GCM。但密钥就在同一 U 盘的 `.keyfile` 里——能读到 U 盘的人就能解密。防的是「顺手翻文件」，不是「拿到 U 盘的人」。 |
| **邮件缓存** | 读过的正文缓存在 `data/cache/`。U 盘丢了，这些邮件就泄露了。 |
| **监听地址** | 只绑定 `127.0.0.1`，同一 WiFi 下的其他人访问不到。 |
| **授权码权限** | 只能 IMAP 收信，**不能**登录网页版、**不能**改密码。随时可在邮箱设置里删除。 |
| **公用电脑** | 用完后请双击「清除数据」，或直接删掉 `data/` 目录。 |

**不要把 `data/` 提交到 git。** 仓库里的 `.gitignore` 已经帮你排除了。

## 实现要点（给想读代码的人）

- **IMAP**：`LOGIN` / `CAPABILITY` / `ID`（163 必需）/ `LIST` / `SELECT` / `UID SEARCH` / `UID FETCH`（头部与全文）/ `UID STORE`，以及 IMAP literal 语法的完整流式解析。
- **MIME**：递归 multipart 解析、嵌套 alternative/mixed、base64 与 quoted-printable、RFC2047 编码字（含**相邻编码字之间的空白必须丢弃**这个规范细节）、中文附件名。
- **并发**：单条 IMAP 连接上用互斥锁串行化命令——否则前端并行刷新文件夹和邮件列表时，两条命令会在同一 socket 上交错并互相打乱响应。
- **U 盘兼容**：exFAT 上 `rename` 覆盖已存在文件会失败，所有写操作都做了降级兜底；`server.pid` 这类附属文件写失败**不会**拖垮服务。

## 已知限制

- **只收不发** —— 目前是纯收件客户端（发信需要 SMTP）。
- **换电脑需重输授权码** —— 仅当 `.keyfile` 与 `config.json` 不同时携带时。
- **macOS Gatekeeper** —— 首次在别人电脑上打开启动器可能被拦，右键 → 打开 即可，或 `xattr -dr com.apple.quarantine <U盘路径>`。
